# 手工织锦试织排机与色线领用复核台

直接打开 `index.html` 使用。在原有纹样排版台基础上，扩展了试织排机、色线领用复核与留档汇总能力。

## 三个业务模块

| 文件 | 职责 |
| --- | --- |
| `rules.js` | 规则模块：全部业务规则（排机准入、超限判定、冻结、失效重算、合格统计），只读写状态对象，不碰页面与存储 |
| `store.js` | 记录存储模块：状态落 `localStorage`，页面重载后状态完整复原 |
| `app.js` | 页面展示模块：渲染与交互，变更一律经 `WeaveRules` 计算、`WeaveStore` 落库后整页重绘 |

## 业务规则

- **纹样**：按编号+版本唯一，重复入库被拒绝，需升版本。
- **排机登记**：登记织机号、经线批次、色线领用单、预计完成日。
  - 同一织机未关机不得承接第二个试织任务（合格工单关机后才释放织机）。
  - 色线不足（库存或领用单额度）或批次过期：只存**待补料**，不占织机；补料/换批次后自动重检上机。
  - 重复或并发提交（同请求键或同纹样活动工单）一律沿用首次工单。
- **试织记录**：录入断线次数、经纬密度、样片结果。
  - 断线>3 次或经密超出 20-80、纬密超出 15-60：只能**返修**；旧结果**留档**但不计入合格统计；同编号纹样的待复核工单**冻结**，返修合格记录入库后自动解冻。
  - 记录合格转**待复核**；复核通过（样片须合格）转**合格**，退回则返修。
- **领用单更正/撤换**：关联排机与合格结论立即失效并重算——旧结论留档、库存返还，按新单重新判定待补料或进行中；撤换生成新单，旧单作废，工单自动迁移。
- **汇总**：合格统计只计当前合格工单，留档记录单独列示；每次变更即落库，页面汇总与重载后状态一致。
