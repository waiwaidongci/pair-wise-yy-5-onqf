# 手工织锦 · 试织排机与色线领用复核台

直接打开 `index.html` 使用（纯前端，数据保存在浏览器 localStorage）。

## 三个业务模块

- `rules.js` **规则模块**：纹样唯一性、织机占用、待补料判定、超限返修判定、合格统计。纯函数，不碰页面与存储。
- `store.js` **记录存储模块**：localStorage 持久化与全部状态变更（排机、试织、复核、冻结/解冻、补料上架、领用单更正/撤换、关机）。
- `app.js` **页面展示模块**：纹样排版台画布 + 排机复核台渲染与交互。所有汇总由存储状态实时推算，刷新页面后状态与汇总一致。

## 业务规则

- 纹样按「编号 + 版本」唯一，重复登记被拒绝；
- 同一织机存在未关机工单时，不得承接第二个试织任务；
- 排机登记织机号、经线批次、色线领用单、预计完成日；色线不足或批次过期只存「待补料」，不占织机；
- 试织记录断线次数、经纬密度、样片结果；断线或密度超限只能返修，相关（同纹样编号+版本）待复核试织冻结；
- 旧结果留档但不计入合格统计；
- 色线领用单更正或撤换后，关联排机与合格结论立即失效并重算；
- 重复或并发排机沿用首次工单（按 纹样+织机 请求键幂等）。
